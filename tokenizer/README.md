# Токенизатор

Из папки `tokenizer` запустите:

```sh
python main.py input.txt
```

Входной файл должен быть в UTF-8. Строки и столбцы считаются с 1; табуляция
считается одним символом. Значение токена выводится как в исходном тексте,
включая кавычки у строк. Ошибки выводятся в stderr.

Запуск тестов из той же папки (нужен pytest):

```sh
python -m pytest -q
```
