# Стековая машина (постфиксная нотация)

Вычисляет выражение в постфиксной нотации и показывает состояние стека на каждом шаге.

Операции: `+`, `-`, `*`, `/` и специальный оператор `~`:

- если оба операнда не равны 0 — в стек кладётся `|x - y|`;
- если хотя бы один равен 0 — весь стек (вместе с операндами) суммируется, сумма возводится в квадрат и кладётся в стек.

## Структура

```
postfix_notation/
├── main.py          # точка входа
├── src/
│   ├── machine.py   # стековая машина
│   └── cli.py       # аргументы командной строки и вывод
└── tests/
    ├── test_machine.py
    └── test_cli.py
```

## Запуск

Нужен Python 3.10+. Команды выполняются из папки `postfix_notation`:

```bash
python3 main.py 3 0 4 ~ 2 ~
```

На Windows вместо `python3` пишется `python`.

Вывод:

```
3  ->  [3]
0  ->  [3, 0]
4  ->  [3, 0, 4]
~  ->  [49]
2  ->  [49, 2]
~  ->  [47]
3 0 4 ~ 2 ~ = 47
```

Кавычки не нужны, но и не мешают: `python3 main.py "3 0 4 ~ 2 ~"` тоже работает.
Если терминал без кавычек подменил `~` на домашнюю папку, а `*` — на список файлов,
программа сама вернёт их обратно.

Справка: `python3 main.py --help`
