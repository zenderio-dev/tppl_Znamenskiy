# Стековая машина (постфиксная нотация)

Вычисляет выражение в постфиксной нотации и показывает состояние стека на каждом шаге.

Операции: `+`, `-`, `*`, `/` и специальный оператор `~`:

- если оба операнда не равны 0 — в стек кладётся `|x - y|`;
- если хотя бы один равен 0 — весь стек (вместе с операндами) суммируется, сумма возводится в квадрат и кладётся в стек.

## Структура

```
postfix_notation/
├── src/
│   ├── machine.py   # стековая машина
│   └── main.py      # запуск из командной строки
└── tests/
    ├── test_machine.py
    └── test_main.py
```

## Запуск

Нужен Python 3.10+. Команды выполняются из папки `postfix_notation`:

```bash
python -m src.main "3 0 4 ~ 2 ~"
```

Вывод:

```
3  ->  [3]
0  ->  [3, 0]
4  ->  [3, 0, 4]
~  ->  [49]
2  ->  [49, 2]
~  ->  [47]
3 0 4 ~ 2 ~ = 47
```

Выражение лучше брать в кавычки, иначе терминал может по-своему понять `*` и `~`.

Справка: `python -m src.main --help`

## Тесты

```bash
pip install pytest coverage
python -m pytest
```

```bash
python -m coverage run --source=src -m pytest
```
